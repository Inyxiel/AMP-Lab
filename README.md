# AMP Lab

AMP Lab is a Baldur's Gate 3 build and inventory optimization project focused on real party/inventory data, item synergies, class/subclass recommendations, and modded rulesets.

## Downloads

Stable Windows builds will be published through **GitHub Releases** rather than committed directly to the repository.

## Status

The repository is being prepared for automated Windows release publishing.

## Security

Secrets such as `.env` files, API keys, local save data, runtime snapshots, and machine-specific configuration must never be committed to this repository.
